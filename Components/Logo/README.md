# Logo

Three variants live in this folder. They are not interchangeable — each has a defined role.

## Lockup — default

`Logo/Lockup/`

The primary logo. Use this unless a specific reason (below) calls for one of the other two. When in doubt, use the Lockup.

Available in Light Mode, Dark Mode, and Mono (Lime Dark, Orange Dark, Pink, Pink Light) — SVG and PNG.

## The Link — restricted use

`Logo/The link/`

Mark-only version (no wordmark). Rarely used standalone.

Approved use cases:
- **Content-page marker in presentations.** On main deck content pages (not covers, not
  dividers), use the small Neutral 100 variant (`Color=Neutral 100.svg`) as a quiet page marker
  in place of eyebrow/kicker text. See `../Presentations/README.md` for placement.

## Rule of thumb

If you're not sure which to use, use the Lockup. Wordmark and The Link require a specific, approved reason — they are not general-purpose substitutes for the Lockup.
